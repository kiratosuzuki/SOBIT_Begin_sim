# SU-RoboLearn

SIGVerse を使用したロボットシミュレータ。

## 概要

SU-RoboLearn は、モバイルマニピュレータやタートルボットを使った初学者向けの教育システムである。Unity ベースのロボットシミュレータであり、専用の Scratch を使用することでロボットの動作、タスク実行などをシミュレーション上で動作させることができる。

本プロジェクトは、人とロボットのインタラクション（HRI）研究向けのシミュレーション基盤である [SIGVerse](https://github.com/SIGVerse) を使用しています。

主な機能：

- モバイルマニピュレータ・タートルボットのシミュレーション
- 複数カメラビュー（バックカメラ・ハンドカメラ・トップカメラ）
- WebSocket による外部制御通信
- テキスト読み上げ（TTS）機能
- カスタマイズ可能なシーン・タスクシナリオ

## システム構成

本システムは Scratch と Unity を WebSocket で接続した構成になっている。

- **Scratch** 上でブロックベースのプログラムを作成し、ロボットへの動作指令を送信する
- **Unity** 上に構築したシミュレータが指令を受け取り、仮想ロボットを動作させる
- ロボットが取得したフィードバック（センサ情報など）も WebSocket で Scratch に返され、条件分岐などに利用できる


## シミュレーション環境

### Simple-Restaurant

タートルボットを使用した環境。ロボットは移動・QR コードの読み取り・発話が可能で、実機や実環境を用意せずに競技を行うことができる。

### Reality-Restaurant

モバイルマニピュレータを使用した、より実環境に近い環境。移動・物体検出・発話に加えてアームによる把持が可能で、配膳や物体の受け渡しといった複雑なタスクに対応している。
